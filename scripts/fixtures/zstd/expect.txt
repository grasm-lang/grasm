# Which fixtures this decoder handles today.
#
# `ok` must decompress to the matching .bin exactly; the name before the first
# dot is the source file, so `text.9` checks `text.bin`. `refused` must fail: a
# decompressor that guesses is worse than one that stops, because a wrong
# answer from a decompressor is indistinguishable from a right one until
# something downstream fails.
#
# Nothing is refused any more. The line is kept because a fixture that must
# fail is as much a check as one that must pass, and the next format feature
# that is not supported belongs here rather than in a comment.
empty      ok        raw block, zero length
empty.9    ok        raw block, zero length
onebyte    ok        raw block, one byte
onebyte.9  ok        raw block, one byte
tiny       ok        raw block
tiny.9     ok        raw block
random     ok        raw block, incompressible
random.9   ok        raw block, incompressible
halfrand   ok        raw and compressed blocks in one frame
halfrand.9 ok        raw and compressed blocks in one frame
zeros      ok        compressed: one match of 3998 at offset 1
zeros.9    ok        compressed: one match of 3998 at offset 1
text       ok        compressed: raw literals, two sequences, a repeat offset
text.9     ok        compressed: raw literals, two sequences, a repeat offset
runs       ok        compressed: an FSE-described sequence table
runs.9     ok        compressed: an FSE-described sequence table
prose      ok        compressed: Huffman literals from FSE-coded weights
prose.9    ok        compressed: Huffman literals from FSE-coded weights
skew        ok       compressed: four-stream Huffman literals
skew.9      ok       compressed: four-stream Huffman literals
skew.blocks ok       three blocks: a reused tree and carried repeat offsets
carry.blocks ok      several blocks: a repeat offset crossing a boundary
