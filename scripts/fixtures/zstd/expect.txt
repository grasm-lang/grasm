# Which fixtures this decoder handles today.
#
# `ok` must decompress to the matching .bin exactly. `refused` must fail: a
# decompressor that guesses is worse than one that stops, because a wrong
# answer from a decompressor is indistinguishable from a right one until
# something downstream fails.
#
# Moving a line from `refused` to `ok` is how progress on compressed blocks
# shows up here.
random   ok        raw block
tiny     ok        raw block
empty    ok        raw block, zero length
zeros    refused   compressed block
text     refused   compressed block
