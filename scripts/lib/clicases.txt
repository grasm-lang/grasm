# Command lines for `scripts/clidiff.sh`: each run by the Rust `grasm` and by
# the one in Grasm (compiler/grasm), each in an empty directory of its own
# that links to every entry at the checkout's root, so a relative path reads
# the checkout and a file a command writes lands in that directory.
#
# A line is the arguments as a shell would split them. A leading word says
# what the two must do:
#
#   (none)      the same stdout, stderr, exit status and files written; a
#               `build --native` success line may differ only in the size and
#               in naming the backend (Cranelift, Grasm)
#   elsewhere   a subcommand part one does not cover: the Grasm command says
#               it is not here, on stderr, and exits 1 (docs/self-hosting.md
#               §6.17); the Rust one does whatever it does
#   runtime     a runtime package built `--native`: the Grasm command writes
#               the runtime's object; the Rust one says there is no `main`
#   target      a `--target` the Grasm backend does not write: refused in its
#               words, where the Rust command emits an ELF or other object or
#               refuses in Cranelift's
#
# Lines starting with `#` and blank lines are not cases.
