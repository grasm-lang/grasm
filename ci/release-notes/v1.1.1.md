The first Grasm release for Linux: archives for x86-64 and arm64, built, run
from an empty directory, published and downloaded again by CI on GitHub's
Ubuntu runners. Each holds `grasm`, `libgrasm_rt_abi.a` (what `--native`
links) and `BUILD-INFO`; `grasm build --native` links with `cc`.

```
curl -fLO https://github.com/grasm-lang/grasm/releases/download/v1.1.1/grasm-linux-x86_64.tar.gz
tar -xzf grasm-linux-x86_64.tar.gz
```

There is no macOS archive in this release. arm64 macOS 26.7 refuses to
start a program with no `LC_UUID` load command, and Grasm's native builds
take the UUID out; until that is fixed, macOS stays on 1.1.0, whose native
builds strip it the same way. `docs/known-issues.md` has this and every
other open defect, including the S1 entries this release ships with.

`CHANGELOG.md` lists the changes since 1.1.0 under 1.1.1.
