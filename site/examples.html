In a browser

10 programs compiled to wasm and run in a tab with no server: a fullstack counter, user registration, a voting app, a blog dashboard, a markdown editor, an upload gallery, a chat router, a collaborative todo list, a SPA router and realtime analytics. Both the count and the list come from the tree — a program runs in a tab when there is a page beside it — because this sentence said twelve while naming three that have none.

All of them live under ProjectGold/ in the repository, with the expected output recorded beside each.
