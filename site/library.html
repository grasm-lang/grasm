Ranges

to_list map filter sum len. A range is a value of type range: it holds three numbers, not its elements, so 0..2_000_000 costs the same as 0..2.

The world

print eprint read_file write_file read_bytes write_bytes list_dir make_dir random_bytes tcp_listen tcp_accept tcp_connect udp_bind net_wait proc_run proc_pipeline — each carrying the effect it performs, so a function that uses one says so in its type.

Every method has a law. Not a recorded expected output — a relation checked against arithmetic, because a bundle is the interpreter and a wrong answer they share is invisible to any comparison between them. A method added to the specification without a law fails the gate by name.
