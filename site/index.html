A systems language

What a program may do
is written in its type.

Grasm puts effects in the signature, capabilities in the package manifest, and ownership in tiers you choose per value. It compiles ahead of time, runs in a browser, and three engines agree byte for byte on every program in the repository.

The signature is the contract

A function's type says what it returns and what it is allowed to do. The row is inferred from the body, so it cannot drift from the truth, and a caller that has not been given io cannot call something that performs it.

fn safe_div(a: i64, b: i64) -> i64 ! MathError {
    if b == 0 {
        fail(DivByZero)
    }
    a / b
}

fn report(n: i64) / {io} {        // this one prints; the type says so
    print("{n}")
}

! MathError is a failure the caller must handle. / {io} is an effect the caller must be permitted. Neither is a comment or a convention — both are checked.

Four engines, one answer

The interpreter is normative. A bundle is that interpreter with the program attached. --native compiles ahead of time through Cranelift. A fourth build targets wasm32. Every gate in the repository exists to hold them to the same answer.

What is different here

Effects, inferred

You do not write the row. The compiler works it out from the body and checks it against what you declared, so a function that starts touching the network stops compiling.

Capability ceilings

A package declares the effects it may perform. One that quietly starts reading files fails to build in every consumer — a compile error, not a code review.

Tiered ownership

Four tiers, chosen per value: borrowed, arena, generational reference, and an explicit unsafe escape. You pay for the one you use.

Typed errors

T ! E is a value. There is no exception mechanism and no null.

Deterministic replay

Every effect can be journaled and replayed on a different engine — a recording made natively replays under the interpreter.

Runs in a browser

The same source, the same answers, compiled to wasm with no server.

Honest about where it is

Grasm compiles real programs — an HTTP server, a SQL engine, a JSON parser, a garbage collector, a self-hosting lexer — and runs them identically on every engine. It has no third-party libraries, no users but this project, and runs at roughly 0.45× native Rust on the benchmark set.
