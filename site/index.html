Systems language · v1.0.0

Your dependencies can read every file you can.

In Python, Go, Rust and Zig, a library that claims to do arithmetic can open your files and your sockets, and nothing in the toolchain will say a word. Grasm makes that a compile error.

Get started How it works Syntax

The manifest is the ceiling

A package declares what it may reach. The compiler infers what it actually does — through every call, into every dependency — and refuses to build when the two disagree.

A patch release tries to grow teeth

Same name, same signature, same result — and one new line that reads a file. This is the whole build:

app — grasm build

The same attack, four toolchains

A trusted pure library’s 1.0.1 starts reading /etc/passwd. scripts/security_bench.sh runs it against four toolchains on every green build. Three of them ship it.

GrasmCOMPILE ERRORinferred effects (io) exceed the declared ceiling ([])

This is the reason the language exists. xz-utils, event-stream, SolarWinds: the attack is always the same shape, and the answer everywhere else is a runtime sandbox or a human reading the diff. Here it is a type error.

Three ideas, and they compose

Capabilities

A package states the effects it may perform. Exceeding it fails the build in every consumer — not in a review, not at run time.

Ownership in tiers

Value semantics by default, a region when a scope should own its allocations, a generational reference when a graph needs one. No lifetime annotations anywhere.

Four engines, one answer

Interpreter, bundle, ahead-of-time native, and wasm. Develop against instant feedback, ship a binary, run the same program in a browser.

Effects are in the type, and inferred

You do not write the row. The compiler works it out from the body and checks it against what you declared, so a function that starts touching the network stops compiling — and so does every caller that was not given the same permission.

The same program, every engine

The interpreter is normative and the other three have to match it. Every gate here exists to hold them to the same bytes.
