Start

Install

One command, and you have the entire toolchain: a single binary, every subcommand inside it, and no runtime to install beside it.

A Rust toolchain bootstraps the compiler the first time, the way every language starts — and none of it survives into what you ship. All four crates a compiled Grasm program links are no_std: the runtime reaches the operating system through grasm_sys, over raw syscalls and libc, never over Rust's standard library. A hello-world is 85.7 KB and nm finds nothing of Rust's in it. How that was done →

Build it

git clone <repository>
cd grasm
cargo build --release --workspace

./target/release/grasm run examples/hello.gr

The binary is target/release/grasm. Put it on your path, or call it where it is.

What you get

CommandDoes
grasm run FILERuns it under the interpreter.
grasm build FILE -o OUTWrites a bundle — one file, runs anywhere.
grasm build FILE --native -o OUTCompiles ahead of time through Cranelift.
grasm build FILE --native --target TRIPLECross-compiles; link against the runtime for that target.
grasm test [DIR]Runs test blocks.
grasm bench [DIR]Runs bench blocks.
grasm check FILETypes and effects only, no output.
grasm fmt [DIR]Formats.
grasm deps [DIR]Resolves dependencies, checks capability ceilings, writes grasm.lock.
grasm journal FILEReads a recording of a program's effects.

Editor support

A language server is in crates/grasm_lsp and a VS Code extension in editors/vscode. A debug adapter is in crates/grasm_dap.

No release binaries yet. Building from source is the only route today. That is on the roadmap.
