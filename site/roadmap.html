Roadmap

Four workstreams toward a first release, running alongside the defect loop rather than instead of it.

1. This site

In progress — you are reading it. What remains: an in-page playground wired to the wasm build, and the tutorial and library reference rendered from docs/ rather than summarised here.

2. Speed

0.45× native Rust today against a 0.95× target, computed by scripts/bench.sh from the numbers it prints. The costs worth attacking, in order: a box per node in tree-shaped data, binary size (328 KB against a 300 KB target), and the atomic reference count every boxed value carries because a parallel body may hold one.

3. Packages and libraries

The mechanism is built: manifests, resolution, lockfiles, path and local registry dependencies, and the capability ceiling. The first two libraries are written. What is missing is a remote registry and the rest of them.

LibraryState
http — serverBuilt. packages/http parses and routes and declares no capability; packages/http_server owns the socket. Both in the corpus, both agreeing on three engines.
http — clientBuilt. packages/http_client. Its demo talks to http_server over a real socket — a Grasm client and a Grasm server.
jsonBuilt. packages/json: parse, render, reach in (get, at, path, as_str…), build up (object, list, with_key…). Declares no capability. The six ProjectGold programs that used it point here.
async — timers, channels, selectNot started. parallel and spawn are in the language; the library above them is not.
testing, log, time, uuid, base64, regexNot started.

The comparison to hyper, axum, tokio, gin and fiber is a comparison against years of work by thousands of people. The honest target for a first release is one good HTTP library, one JSON library, one async library, and the packaging to publish them — so that the second and third can be written by somebody else.

4. Is the compiler ready

Yes, with the limits on the status page stated rather than glossed. Four engines agree; the list of shapes the native backend cannot compile is one entry long and permanent.

The bar for calling it finished

Zero known defects, every gate green, and two consecutive independent review rounds finding nothing new — each conducted by someone who has seen only the language pack, not this repository's history. Those rounds have not run. Until they do, the claim is not available, and no number of green gates substitutes for it.
