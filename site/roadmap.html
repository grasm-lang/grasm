Roadmap

Four workstreams toward a first release, running alongside the defect loop rather than instead of it.

1. This site

In progress — you are reading it. The playground now runs programs in the page, on the same wasm module the gates hold to the other engines, and the tutorial and library reference are the documents themselves, rendered when the site is written rather than summarised here.

2. Speed

0.965× of native Rust against a 0.95× target, computed by scripts/bench.sh from the numbers it prints, so the goal is met and the suite still has a worst row at 0.51×: tree, which pays a box per node in tree-shaped data. Storing those nodes inline was built and measured at 1.33× slower — a node's release turns into a runtime call — so the release has to get cheaper before the representation can change. Binary size is no longer on this list: 85.7 KB against a 300 KB target. What is left, in order: the release path, the atomic reference count every boxed value carries because a parallel body may hold one, and borrowed string views, which is what the etl benchmark loses 3.6× to.

3. Packages and libraries

The mechanism is built: manifests, resolution, lockfiles, path and local registry dependencies, and the capability ceiling. 651 libraries are written, all of them inside this repository. What is missing is a remote registry — nothing fetches and nothing publishes, so nobody else can write the next one.

This table used to list six libraries as not started — testing, log, time, uuid, base64 and regex. All six exist. What it tracks now is the shape of the set rather than a checklist of names:

AreaState
http — server and clientBuilt. packages/http parses and routes and declares no capability; http_server owns the socket; http_client's demo talks to http_server over a real one. There is http2frame, http2client and https_client besides.
jsonBuilt, and so are jsonschema, jsonpath, jsonpatch, jsonpointer and jsonmergepatch. All declare no capability.
ConcurrencyIn the language rather than a library. Channels, concurrent/go, actors and chan_select are in, 1,000,000 tasks run in 22 s on a compiled build, and net_wait holds many connections on one thread. A task still refuses every effect, which is the half of G6 that is open, and there is no timer library above any of it.
Everything else651 libraries, the six that were listed as missing among them. See Packages.
A registryThe one that matters, and it is not built. Nothing fetches and nothing publishes, so every library here had to be written here — which is also why there are 651 of them.

The comparison to hyper, axum, tokio, gin and fiber is a comparison against years of work by thousands of people, and a count does not close it: these are 651 libraries with one set of eyes on them and no production use behind any of them. The honest target for a first release is the packaging to publish them — so that the next one can be written by somebody else.

4. Is the compiler ready

Yes, with the limits on the status page stated rather than glossed. Four engines agree; the list of shapes the native backend cannot compile is one entry long and permanent.

The bar for calling it finished

Zero known defects, every gate green, and two consecutive independent review rounds finding nothing new — each conducted by someone who has seen only the language pack, not this repository's history. Those rounds have not run. Until they do, the claim is not available, and no number of green gates substitutes for it.
