# G7 and G9, measured

## G9 — "zero-cost C ABI, no hand-written bindings"

**No hand-written bindings: met.** `bindgen` reads a preprocessed header and
writes the declarations -- 275 functions and 198 constants out of
`sqlite3.h` -- and `--link` puts the library on the link line. See
`docs/bindgen.md`.

**Zero-cost: nearly, and the gap is about one cycle.** The worst case for this
measurement is a C function that does nothing, because then the call overhead
is the entire cost. `long g9_add(long, long)` in a static archive, called
twenty million times, medians of seven interleaved rounds:

| | |
|---|---:|
| C calling C | **21 ms** |
| Grasm calling C | **28 ms** |

1.33x, which at twenty million calls is **0.35 ns per call** -- roughly one
cycle on this machine. For a C function that does any real work the difference
is unmeasurable; for one that adds two integers it is a third.

So "zero-cost" as written is not quite true, and the honest claim is that the
boundary costs about a cycle and nothing is marshalled: an `i64` crosses as
itself.

**Still missing:** a struct passed or returned by value cannot cross, which
rules out some graphics APIs until it is fixed.

## G7 — "capability-sandboxed deps, 100% of registry packages"

The enforcement works and is precise. A package declaring `capabilities = []`
that prints is refused, naming the file and the line:

    error: package `noline` performs `io` but its manifest only permits nothing
      performed: `io` at ../noline/src/main.gr:3:5

**But omitting the key means unrestricted, not empty** -- and that is
deliberate, stated in [T-CAPABILITY]: *"`capabilities = []` says 'performs
nothing'; leaving it out says 'do not check me'."* A dependency with no key
performs `io` unchecked, which was verified rather than assumed.

54 of 838 packages here had no key. None of them reached outside, so the
exposure was nil, but the ceiling was opt-in where G7 asks for 100%.

**Changed, 2026-10-07.** The language keeps its rule -- a directory of files
you are editing should not need the key. `grasm publish` now refuses a package
without one:

    error: package `noline` has no `capabilities` key, so nothing about what it
    may reach is checked for the people who depend on it
      add `capabilities = []` if it performs nothing, or list what it performs

That is the exact scope G7 asks for: **registry** packages. All 54 manifests
now carry `capabilities = []`, so 838 of 838 declare a ceiling and the
compiler checks every one of them.

**Still missing:** reproducible builds are untested, and there is no remote
registry -- nothing fetches, publishes or verifies over a network.
