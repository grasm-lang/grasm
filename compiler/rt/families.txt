# The runtime's families and where each symbol stands (docs/self-hosting.md
# §6.7). `scripts/rtswap.sh` reads this and holds the Grasm runtime to it.
#
#   <family> <name>    moved: the Grasm runtime exports `grt_<name>`, and
#                      every program's `grasm_<name>` must bind to it
#   state <name> ...   the Grasm runtime may call the Rust runtime's
#                      `grasm_<name>`: state the Rust code still linked shares
#   backend <name> ... the backend emits a call to `grasm_<name>` in the
#                      Grasm runtime's own code, as it does in any program's
#
# A moved name the Grasm runtime does not export, an export not listed here,
# or a call to any other `grasm_` name fails the gate: that is a family
# falling back to Rust without saying so.
